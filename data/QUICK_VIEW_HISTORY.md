# 快速了解本项目的处理效果指南

本文档介绍了如何通过历史记录功能快速查看之前处理过的文档分析报告和生成的Schema，帮助您快速了解本项目的处理效果。

## 1. 查看历史文档分析报告

要查看历史文档分析报告，请按照以下步骤操作：

1. **进入历史记录页面**
   - 打开系统界面，进入"📄 文档分析"标签页

2. **刷新并选择历史记录**
   - 点击"📂 加载报告"按钮旁边的"🔄"刷新按钮
   - 系统会列出所有保存的历史分析报告文件
   - 在列表中选择一个以`.json`结尾的报告文件

3. **加载选中记录**
   - 点击"📂 加载选中报告"按钮
   - 系统会自动加载并显示该历史报告的详细内容

4. **查看报告详情**
   - 在"📊 报告预览"标签页中可以查看报告的格式化展示
   - 在"✏️ 编辑报告"标签页中可以查看和编辑原始JSON格式的报告
   - 在"🏷️ 领域信息"标签页中可以查看识别的领域相关信息

加载成功后，您可以在文档分析页面看到历史处理过的文档报告内容，包括实体、关系、属性等分析结果。

## 2. 查看历史Schema

要查看历史生成的Schema，请按照以下步骤操作：

1. **进入Schema生成页面**
   - 切换到"🏗️ Schema生成"标签页

2. **刷新并选择历史Schema**
   - 在"📂 加载历史Schema"区域点击"🔄"刷新按钮
   - 系统会列出所有保存的历史Schema文件（.yaml格式）
   - 从下拉列表中选择一个历史Schema文件

3. **加载选中Schema**
   - 点击"📂 加载选中Schema"按钮
   - 系统会自动加载并显示该历史Schema的内容

4. **查看Schema详情**
   - 在"📝 Schema编辑器"标签页中可以查看和编辑Schema内容
   - 在"🔍 验证结果"标签页中可以查看Schema的验证结果

加载成功后，您可以在右侧的编辑区域看到历史Schema的完整内容。

## 3. 查看Schema图谱可视化效果

为了更直观地查看Schema结构，您可以生成实体关系图：

1. **进入导出与可视化页面**
   - 切换到"📦 导出与可视化"标签页

2. **生成实体关系图**
   - 点击"🎨 生成实体关系图"按钮
   - 系统会根据当前加载的Schema生成可视化图表

3. **查看可视化效果**
   - 系统支持两种可视化形式：
     - **ER图**：传统的实体关系图形式
     - **知识图谱视图**：力导向图布局的交互式图谱（默认启用）
   - 可通过勾选/取消勾选"知识图谱视图"选项切换显示形式
   - 在知识图谱视图中，您可以：
     - 拖拽节点调整位置
     - 滚轮缩放视图
     - 点击节点高亮相关关系

通过这种方式，您可以直观地查看Schema中实体、属性和关系之间的连接关系，便于理解和分析历史处理效果。

## 小贴士

- 历史文件均保存在 `data/output/` 目录下
- 报告文件以 `report_` 开头，Schema文件以 `schema_` 开头
- 所有文件都带有时间戳，方便识别处理时间
- 建议定期整理历史文件，删除不需要的版本以节省存储空间
